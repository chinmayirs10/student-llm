# StudentLLM: Simulating Learner Behaviour with Large Language Models

> Research project on using LLMs to simulate **realistic, persona-consistent students** in tutoring conversations, to support the evaluation of AI tutors in education.

🎓 *Ongoing Master's thesis research. Methods and results will be shared after publication.*
🔒 *Source code is private.*

---

## 🎯 Motivation
Evaluating AI tutors needs many learners with different backgrounds and behaviours. Real student studies are slow and expensive, and LLMs prompted to "act like a student" tend to drift out of character over a conversation.

This project explores how LLMs can simulate learners that stay **consistent with a target profile** across multi-turn tutoring dialogues.

## 🧭 Project Journey
- **Phase 1: University course project.** Persona-conditioned tutoring dialogues with an iterative generate → evaluate → regenerate workflow.
- **Phase 2: Master's thesis (ongoing).** Extended into a research system with systematic experiments on persona consistency.
